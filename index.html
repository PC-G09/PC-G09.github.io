01 / THE PROBLEM

From resource limits to weighted human capability.

GPS addresses W-MSRCPSP: a software project scheduling problem where tasks have precedence relationships, skills are required, and people differ in proficiency across those skills.

01RCPSP

Resources + precedence

Schedule activities while respecting task dependencies and scarce renewable resources.

02MSRCPSP

Skills enter the model

Each task demands skills, while each human resource can contribute one or more skills.

03W-MSRCPSP

Proficiency becomes weighted

Resources are heterogeneous: skill proficiency is represented by a weight in the interval [0, 1].

02 / RESEARCH CONTRIBUTION

The paper changes what “available” means.

A resource is not represented as interchangeable capacity. Each person carries skill-specific proficiency weights, and GPS keeps revisiting allocation as parallel tasks finish at different times.

04

Best-fit resource assignment

AssignResources

Inputtᵢ, Rₐᵥₐᵢₗ
OutputBoolean
  1. Visit every skill required by the task.
  2. Choose the available matching resource with maximum proficiency.
  3. Recalculate the task-skill finish time after every assignment.
  4. Stop once the paper’s deadline condition is met; roll back on failure.

InputT∥, Rₐᵥₐᵢₗ

  2. Select the latest-finishing scheduled task and skill.

06 / CONCLUSION

Use proficiency. Reuse capacity. Protect parallelism.

GPS combines best-fit weighted assignment with parallel scheduling, then keeps resources productive as task finish times diverge.

GPS performs particularly well when
  • More resources are available
  • Skill and resource demand are lower
  • Graph complexity leaves more parallel tasks
  • Task-duration ranges create early resource releases
The GPS–PSS gap becomes smaller when
  • More skills are required per task
  • Graph complexity reduces parallelism
  • Resource demand per skill increases
Evidence scope

Simulation-based evaluation

Seven experiments, 50 project instances each, across six modeled scheduling factors and a primary comparison against PSS.

Supported limitations

Bounded comparison

The study is simulation-based, compares mainly with PSS, and models a limited set of factors and resource-allocation constraints.

Author-stated future work

Broader allocation model

Incorporate additional factors and constraints in resource allocation, while further improving and optimizing GPS.
